# Fotografie · Dario Coluzzi

Album fotografici, pubblicati con GitHub Pages. Il sito è in inglese.

- **Terra rossa** (Arizona, Utah e Nevada, 5–11 aprile 2026): `album/usa-2026/`
- **Note piemontesi** (Piemonte, 2024–2026): `album/piedmont/`
- **Casa mia** (costa del Lazio meridionale, 2022–2026): `album/lazio/`
- **Con il muso all’insù** (Aeritalia e Pratica di Mare, 2023–2026): `album/airshows/`

Ogni album ha la sua cartella dentro `album/` (pagina, foto, testi, mappa); `home/` contiene testi e foto di copertina della home; `common/` stile, script, impostazioni e il codice che genera le pagine. Dettagli e istruzioni in [common/README.md](common/README.md).

Per rigenerare il sito: `python3 common/code/build_site.py`. Anteprima: `python3 -m http.server 8000`, poi http://localhost:8000.
