# Fotografie · Dario Coluzzi

Album fotografici, pubblicati con GitHub Pages, in italiano e in inglese.

- **Terra rossa** (Arizona, Utah e Nevada, 5–11 aprile 2026): `usa-2026/`

Ogni album ha la sua cartella (pagina, foto, testi, mappa); `home/` contiene testi e versione inglese della home; `common/` stile, script, impostazioni e il codice che genera le pagine. Dettagli e istruzioni in [common/README.md](common/README.md).

Per rigenerare il sito: `python3 common/code/build_site.py`. Anteprima: `python3 -m http.server 8000`, poi http://localhost:8000.
